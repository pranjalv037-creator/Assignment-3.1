5. How to Run


1. Create a folder named Assignment-3.1.
2. Save the first code as index.html.
3. Save the second code as about.html in the same folder.
4. Open index.html in a web browser.
5. Click Home and About to test the navigation links.
6. Click Wikipedia to verify that the external link opens in a new tab.
